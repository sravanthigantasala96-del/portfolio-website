# Sai Sravanthi G - Portfolio Website

An interactive portfolio website built with React to demonstrate learning experience and showcase professional profile. This project demonstrates React concepts including components, JSX, state management, routing, and hooks.

## 🌐 Live Website

**https://sravanthigantasala96-del.github.io/portfolio-website**

## Features

- **Component-Based Architecture**: Modular, reusable React components
- **React Router**: Multi-page navigation with routing
- **React Hooks**: useState and useEffect for state management
- **JSX**: Declarative UI rendering
- **Interactive UI**: Dynamic content, tabs, filters, and animations
- **Responsive Design**: Mobile-friendly layout
- **Modern Styling**: Professional design inspired by Danske Bank styling

## React Concepts Demonstrated

1. **JS Frameworks & JSX**: Used throughout the application
2. **React Components**: Component-based architecture with reusable components
3. **Styling Components**: CSS modules and component-specific styling
4. **State Management**: useState hook for managing component state
5. **Routing**: React Router DOM for navigation between pages
6. **React Hooks**: useState, useEffect for state and side effects

## Installation

1. Navigate to the project directory:
```bash
cd portfolio-website
```

2. Install dependencies:
```bash
npm install
```

## Running the Application

Start the development server:
```bash
npm start
```

The application will open at [http://localhost:3000](http://localhost:3000)

## Building for Production

Create an optimized production build:
```bash
npm run build
```

## Deployment

Deploy to GitHub Pages:
```bash
npm run deploy
```

## Pages

- **Home**: Hero section with role animation and quick links
- **About**: Personal overview with tabbed interface
- **Experience**: Professional experience with interactive company selector
- **Education**: Education history with expandable cards
- **Skills**: Technical skills with category filters and progress bars
- **Projects**: Project showcase with React concepts demonstration

## Technologies Used

- React 18.2.0
- React Router DOM 6.20.0
- CSS3 (Animations, Flexbox, Grid)
- JavaScript ES6+
